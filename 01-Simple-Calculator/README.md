# 🧮 Simple Calculator

A beginner-friendly **C programming project** that performs basic arithmetic operations using user input.

This project was built while learning and practicing core C programming concepts.

## ✨ Features

* Addition (`+`)
* Subtraction (`-`)
* Multiplication (`*`)
* Integer Division (`/`)
* Modulus / Remainder (`%`)
* Division by zero protection
* Invalid operator handling
* Calculate again option

## 🛠️ Technologies Used

* **C Programming**
* **VS Code**
* **GCC Compiler**
* **Windows**

## 📚 C Concepts Used

* `printf()` and `scanf()`
* Variables
* Data Types
* Arithmetic Operators
* `if-else if-else`
* Character input
* `do-while` loop
* Comparison and logical operators
* Basic error handling

## ▶️ How to Run

### 1. Compile the program

```bash
gcc calculator.c -o calculator
```

### 2. Run the program

```bash
./calculator
```

On Windows, you can also run:

```bash
calculator.exe
```

## 💻 Example

```text
Enter first number: 20
Enter operator (+, -, *, /, %): *
Enter second number: 5

Result = 100

Calculate again? (y/n): n

Thank you for using calculator!
```
